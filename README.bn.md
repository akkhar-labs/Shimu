# শিমু — নির্দেশিকা-১৬ আর্কিটেকচারের জন্য ভার্চুয়াল সিপিইউ

**শিমু** হলো **নির্দেশিকা-১৬** (Nirdeshika-16) যন্ত্র-বিধানের জন্য তৈরি একটি রেফারেন্স সিমুলেটর বা ভার্চুয়াল সিপিইউ। এটি 'বয়ন' (Boyon) অ্যাসেম্বলার থেকে পাওয়া র-বাইনারি `.ব` ফাইলগুলো সরাসরি মেমোরিতে লোড করে এবং একটি বাস্তব প্রসেসরের মতো সেগুলো কার্যকর করে।

সমস্ত আউটপুট বাংলা ভাষায় এবং দেশীয় **অক্ষর-হেক্স** পদ্ধতিতে দেখানো হয়।

---

## বৈশিষ্ট্যসমূহ

- **১৬টি ওকোড** — নির্দেশিকা-১৬-এর পূর্ণাঙ্গ নির্দেশ সেট: পাটিগণিত, লজিক, লাফ, ইনপুট/আউটপুট ও থামো
- **৬৪ কিলোবাইট ভার্চুয়াল মেমোরি** — ৬৫,৫৩৬ বাইটের সফটওয়্যার-নিয়ন্ত্রিত র‍্যাম (লিটল-এন্ডিয়ান)
- **১৬টি রেজিস্টার** — ১৩টি সাধারণ (S0–S11) + ৩টি বিশেষ (PC, SP, ফ্ল্যাগ)
- **ফেচ-ডিকোড-এক্সিকিউট লুপ** — হার্ডওয়্যার স্তরে নির্দেশ চক্র সম্পাদন
- **বাংলা আউটপুট** — রেজিস্টারের মান, ঠিকানা এবং ফলাফল বাংলা সংখ্যা ও অক্ষর-হেক্সে প্রদর্শিত
- **অক্ষর-হেক্স পদ্ধতি** — একটি সার্বভৌম ষোড়শিক পদ্ধতি যেখানে বাংলা অঙ্ক (`০`–`৯`) এবং ব্যঞ্জনবর্ণ (`ক`–`চ`) ব্যবহার করা হয়
- **স্থিতি-ফ্ল্যাগ** — শূন্য (Zero), উপচয় (Overflow) ও ঋণাত্মক (Negative) — প্রতিটি কাজের পর হালনাগাদ হয়
- **শূন্য দিয়ে ভাগ সুরক্ষা** — শূন্য দিয়ে ভাগ করলে এক্সিকিউশন থামে এবং বাংলায় ত্রুটি বার্তা দেখায়
- **স্ট্রিম-ভিত্তিক আউটপুট** — `সিমুলেটর_ফলাফল.txt` ফাইলে বিস্তারিত রিপোর্ট তৈরি করে

## ইনস্টলেশন

### প্রয়োজনীয় সরঞ্জাম

- GCC (বা যেকোনো C99-সামঞ্জস্যপূর্ণ কম্পাইলার)
- Make

### বিল্ড

```bash
make
```

বা নিজে কম্পাইল করুন:

```bash
gcc -Iinclude src/main.c src/cpu.c src/memory.c src/alu.c src/io.c src/utils/formatting.c -o bin/shimu
```

বাইনারি ফাইল `bin/shimu` (উইন্ডোজে `bin/shimu.exe`) ফোল্ডারে তৈরি হবে।

---

## ব্যবহার

```bash
./bin/shimu <ফাইল.ব>
```

উদাহরণ:

```bash
./bin/shimu examples/গণিত.ব
```

শিমু বাইনারি ফাইলটি ঠিকানা ০ থেকে ভার্চুয়াল মেমোরিতে লোড করে, তারপর ফেচ-ডিকোড-এক্সিকিউট লুপ চালায় — যতক্ষণ না `থামো` (HALT) নির্দেশ আসে বা মেমোরির সীমা অতিক্রম করে।

## আউটপুট ব্যাখ্যা

শিমু দুই জায়গায় ফলাফল দেখায়:

1. **টার্মিনাল** — শুরুবার্তা, কত বাইট লোড হয়েছে এবং আউটপুট ফাইলের পথ
2. **`সিমুলেটর_ফলাফল.txt`** — বিস্তারিত সিমুলেশন রিপোর্ট:
   - `প্রদর্শন` (OUT) নির্দেশের আউটপুট
   - থামার নিশ্চিতকরণ
   - সর্বশেষ রেজিস্টার অবস্থা (১৬টি রেজিস্টার অক্ষর-হেক্সে)

### নমুনা আউটপুট

```
--- নির্দেশিকা-১৬ সিমুলেশন রিপোর্ট ---
আর্কিটেক্ট: রাহাত হাসান | অক্ষর ল্যাবস

[আউটপুট] সাময়িক-১ এর বর্তমান মান: ৪০ (ষোড়শিক: ০ষ২৮)

সিস্টেম: প্রসেসর থামানো হয়েছে (থামো).

--- রেজিস্টার অবস্থা (চূড়ান্ত অবস্থা) ---
সাময়িক-০: ০ষ০   সাময়িক-১: ০ষ২৮   সাময়িক-২: ০ষ০   ...
```

## ভাষা-কৌশল

শিমু **অক্ষর ল্যাবস** ইকোসিস্টেমের অংশ। এর মূল নীতি: **নিজের ভাষায় কম্পিউটিং**।

- সব সোর্স কোড মন্তব্য বাংলায় লেখা
- সব রানটাইম আউটপুট বাংলায়
- সংখ্যা পদ্ধতি বাংলা অঙ্ক ব্যবহার করে (`০ ১ ২ ৩ ৪ ৫ ৬ ৭ ৮ ৯`)
- ষোড়শিক পদ্ধতি (অক্ষর-হেক্স) বাংলা ব্যঞ্জনবর্ণ ব্যবহার করে (`ক খ গ ঘ ঙ চ`) ১০-১৫ মানের জন্য

এর মানে, একজন বাংলাভাষী ব্যবহারকারী ইংরেজি বা লাতিন বর্ণমালা না জেনেও সিমুলেটরের আউটপুট বুঝতে পারেন।

## ডেভেলপমেন্ট

### বিল্ড

```bash
make
```

### নতুন ওকোড যোগ করা

1. `include/arch/nirdeshika16.h`-এ `Opcode` এনামে নতুন ওকোড যোগ করুন
2. `src/cpu.c`-এর `step_cpu()` ফাংশনের `switch` ব্লকে কেস ইমপ্লিমেন্ট করুন
3. প্রয়োজন হলে অপারেন্ড ডিকোডার ম্যাক্রো আপডেট করুন

### টেস্টিং

বয়ন অ্যাসেম্বলার দিয়ে একটি `.ব` বাইনারি ফাইল তৈরি করুন, শিমু দিয়ে রান করুন এবং `সিমুলেটর_ফলাফল.txt` আউটপুট দেখুন।
